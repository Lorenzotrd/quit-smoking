# Quit Smoking for Codex

Before starting coding work, run or remind:

```bash
quit-smoking check
```

The dashboard opens immediately after 2-3 questions and shows:

- 3D lung condition
- Lifetime cigarette estimate
- Smoke-free streak
- Solutions by trigger
- Allen Carr-inspired quitting stages

Tone:
Strict, useful. Roast the addiction, not the user.
